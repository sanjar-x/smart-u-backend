### Основные конструкции и функции SQL в SQLAlchemy

Манипуляция данными и таблицами
select - Осуществляет выборку данных из базы.
insert - Для вставки данных в таблицу.
update - Обновляет существующие данные в таблице.
delete - Удаляет данные из таблицы.


Соединения и объединения
join - Присоединяет одну таблицу к другой.
outerjoin - Выполняет внешнее соединение таблиц.
fulljoin - Полное соединение таблиц, возвращает строки при наличии совпадения в одной из таблиц.

Сортировка и фильтрация
group_by - Группирует результаты по одному или нескольким столбцам.
order_by - Сортирует результаты запроса.
having - Условие фильтрации, применяемое к результатам группировки.
distinct - Возвращает только различные (уникальные) строки.
limit - Ограничивает количество строк в результате.
offset - Пропускает указанное количество строк перед началом вывода результатов.

Логические и сравнительные операции
asc - Сортировка по возрастанию.
desc - Сортировка по убыванию.
between - Проверка значения на вхождение в интервал.
like - Поиск по шаблону.
in_ - Проверка на вхождение в указанный список.
not_ - Логическое отрицание условия.
and_ - Логическое "И" между условиями.
or_ - Логическое "ИЛИ" между условиями.
case - Условное выражение (аналог CASE в SQL).
exists - Проверяет наличие строк, удовлетворяющих условию.
any_ - Проверка наличия любого значения, удовлетворяющего условию, в подзапросе.
all_ - Проверка, что все значения в подзапросе удовлетворяют условию.


Функции и выражения
func - Позволяет обращаться к SQL функциям.
cast - Приведение типа данных.
extract - Извлечение определенной части даты.
bitwise_not - Операция побитового НЕ.
collate - Указывает, как должны сравниваться и сортироваться строки.
false - Константа для представления логического "ложь".
null - Представляет SQL NULL.
nulls_first - Указывает, что значения NULL должны идти перед всеми другими значениями.
nulls_last - Указывает, что значения NULL должны идти после всех других значений.


Агрегатные функции в SQL и SQLAlchemy
sum - Считает сумму значений по указанному столбцу.
avg (average) - Вычисляет среднее значение по указанному столбцу.
count - Подсчитывает количество значений (или уникальных значений при использовании с DISTINCT) в указанном столбце.
min - Находит минимальное значение в столбце.
max - Находит максимальное значение в столбце.

Дополнительные конструкции и управление транзакциями
alias - Создает SQL псевдоним для таблицы или выражения.
subquery - Создание подзапроса.
union - Объединяет результаты двух запросов.
union_all - Объединяет результаты двух запросов, включая все дубликаты.
intersect - Возвращает пересечение результатов двух запросов.
label - Позволяет задать псевдоним для столбца в результате запроса.
tuple_ - Создание кортежей в SQL-выражениях.
savepoint - Управление точками сохранения в транзакциях, что позволяет откатываться к определённым точкам внутри транзакции.
rollback - Операция для отката транзакций до последней точки сохранения или начала транзакции.
commit - Фиксация транзакций, подтверждение изменений данных в базе.
synonym - Функциональность для определения синонимов в SQL-запросах, позволяющая ссылаться на столбцы или таблицы под другими именами.
check - Определение ограничений CHECK в SQL, которое позволяет указать условие, которому должны удовлетворять данные в столбце.
sequence - Создание и управление последовательностями, которые являются объектами баз данных, генерирующими последовательные числовые значения.
trigger - Работа с триггерами, которые автоматически выполняют указанные операции в ответ на различные события в базе данных.
partition_by - Используется в оконных функциях для разделения набора строк на разделы, в рамках которых выполняется функция.
